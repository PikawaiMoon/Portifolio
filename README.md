# Meu Portfólio

Portfólio pessoal feito com HTML, CSS e JavaScript.

## Como publicar no GitHub Pages

1. Crie uma conta em https://github.com (se ainda não tiver).
2. Clique em **New repository**.
   - Para o endereço ficar `https://SEU-USUARIO.github.io`, o nome do repositório precisa ser exatamente `SEU-USUARIO.github.io`.
   - Deixe como **Public**.
3. Clique em **uploading an existing file** e envie os arquivos `index.html`, `style.css`, `script.js` e `README.md`. Depois clique em **Commit changes**.
4. Vá em **Settings → Pages**. Em **Branch**, escolha `main` e a pasta `/ (root)`, e clique em **Save**.
5. Espere 1 ou 2 minutos e acesse `https://SEU-USUARIO.github.io`.

## O que trocar no `index.html`

Procure estes textos e troque pelos seus dados:

- `SEU NOME` / `SEU NOME COMPLETO` / `SeuNome`
- `SEU-USUARIO` (link do seu GitHub, nos cards de projetos)
- Os cards da seção **Projetos** (nome, descrição, linguagens e link)

## Estrutura

```
index.html   → conteúdo da página
style.css    → visual e responsividade
script.js    → menu do celular e animações
```
